# Signal over noise

A personal GitHub profile for Antariksh Das, built around inspectable public work.

## Visual system

- Midnight navy / warm ivory, burnt orange, and mint.
- Oversized editorial type with an orbital wireframe.
- Separate light, dark, mobile, and desktop SVG assets.
- A 65-second orbit and 42-second satellite rotation on the desktop hero.
- `prefers-reduced-motion` disables animation; every image has a complete static state.
- Every project card links directly to its repository. A plain-text index follows the cards.
- All artwork lives in this repository. There are no remote stats widgets, tracking pixels, or scheduled updates.

## Editing

Update the prose and links in `README.md`. Artwork is standard SVG in `assets/`; each illustration has matching desktop/mobile and light/dark versions. Keep SVGs self-contained and retain their title elements. The profile uses relative asset paths so previews also work inside the repository.

The gallery describes project scope. It does not claim deployment status, investment performance, model accuracy, or sole authorship of collaborative work.
